# НИЖЕ

Одиночный браузерный прототип экспедиции в разлом на Three.js. Спуститесь по уступам и мостам, изучите три образца и доберитесь до нижней площадки. Seed меняет форму скал и положение переходов в пределах трёхъярусной схемы.

```sh
npm ci
npm run dev
```

Откройте http://localhost:5173. Для пешего спуска используйте WASD и мышь. F включает фонарь, E изучает образец рядом, Esc освобождает курсор. Seed можно ввести вручную или заменить кнопкой ↻. «Осмотреть маршрут» ведёт камеру до нижней площадки, а «Свободная камера» позволяет рассмотреть разлом с другой стороны.

`npm test` проверяет генерацию и проходимость маршрутов. `npm run build` собирает приложение. Для сценария Chromium установите браузер командой `npx playwright install chromium` и запустите `npm run test:browser` при работающем сервере. Переменная `CAVES_CHROMIUM` позволяет использовать системный Chromium.
