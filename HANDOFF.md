# НИЖЕ · передача работы

## Цель

Исследовать процедурную генерацию пещер для кооператива на 3–4 игроков, затем довести идею до первого проверяемого прототипа. Пользователь попросил остановиться после играбельного одиночного спуска.

## Что готово

- Исследование генераторов и темпа встреч в других играх. Предложение для проекта описывает граф маршрутов, скальную оболочку и подготовленные шахтные конструкции.
- Одиночный прототип на Three.js и Vite. Три яруса, два моста, боковой обход, кристаллы и нижняя площадка. Seed воспроизводит план и оформление.
- Пеший режим от первого лица, обзор маршрута до нижней площадки и свободная камера. Есть схема спуска, фонарь, три образца и короткая справка по управлению.

## Проверка

Выполнить `npm ci`, затем `npm test` и `npm run build`. Для ручного прогона запустить `npm run dev` и открыть порт 5173. WASD и мышь управляют спуском, F переключает фонарь, E изучает ближайший образец, Esc освобождает курсор.

С работающим сервером выполнить `npm run test:browser`. Если используется системный Chromium, задать `CAVES_CHROMIUM=/usr/bin/chromium`. В последнем прогоне прошли сборка, проверка проходимости на 150 seed и сценарий Chromium на собранной версии. Сценарий проверяет пешее движение, фонарь, освобождение курсора, свободную камеру, смену seed, обзор до нижней площадки и сбор одного образца на обратном пути.

## Ограничения и зависимости

- Кооператив, враги, управление напряжением и разрушаемая порода остаются частью концепции. Форма скал и координаты переходов меняются, а общая схема маршрута сохраняется.
- Перемещение опирается на проверку поверхности маршрута. Падения за край отключены. Производительность на целевых устройствах и управление на реальном телефоне отдельно не измерялись. Vite выдаёт предупреждение о размере JS-пакета.
- Другие задачи для запуска не нужны. Зависимости зафиксированы в lock-файле, браузеру нужен WebGL 2. `node_modules/`, `dist/` и скриншоты в `artifacts/` остаются локальными, сценарий Chromium может создать скриншоты заново.
- На момент сохранения у исходного checkout не было коммитов. Эта WIP-ветка начинается с корневого снимка. Для будущей интеграции это важно при выборе способа переноса изменений.
